Run `node docs/upskill/09-independent-practice/verify-routes.mjs` from the repository root to check those references against the current source catalogs. This bounded check reads files only and uses Node built-ins. It does not create study progress or prove completion of an exercise.

Read the assignment before the reference. Keep initial predictions, failed experiments, and later corrections in your own evidence journal. A passed test against supplied reference code should be labeled reference verification, never your independent implementation result.
